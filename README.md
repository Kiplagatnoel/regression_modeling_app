# regression_modeling_app

A Shiny Healthcare Analytics Dashboard Using  Simulated Healthcare Data for Linear Regression

## Features

- Interactive web application built with R Shiny
- Responsive design
- Automated deployment with GitHub Actions

## Local Development

To run this application locally:

```r
# Install required packages
install.packages(c("shiny", "renv"))

# Run the application
shiny::runApp()
```
